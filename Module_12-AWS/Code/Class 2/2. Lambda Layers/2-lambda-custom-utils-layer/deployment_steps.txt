=============================================
  Lambda Layer Concept & Deployment Steps
=============================================

WHAT IS A LAMBDA LAYER?
  - A Layer is a .zip containing reusable code (libraries/utilities)
  - It gets extracted to /opt/python/ at runtime
  - Multiple Lambda functions can share the same Layer
  - Keeps your function code small and clean

FOLDER STRUCTURE:
  lambda_layer_example_v2/
  |-- lambda_function.py          <-- Your Lambda function code (zip this separately)
  |-- layer_code/
      |-- python/
          |-- utils.py            <-- Layer code (MUST be inside python/ folder)


=============================================
  STEP-BY-STEP DEPLOYMENT
=============================================

STEP 1: Create the Layer zip
   cd layer_code
   zip -r ../utils_layer.zip python/

STEP 2: Upload the Layer in AWS Console
   - Go to AWS Lambda -> Layers -> Create Layer
   - Name: unit-converter-layer
   - Upload: utils_layer.zip
   - Compatible runtime: Python 3.14
   - Click Create

STEP 3: Create the Lambda function zip
   zip function.zip lambda_function.py

STEP 4: Create the Lambda function in AWS Console
   - Go to AWS Lambda -> Create Function
   - Function name: unit-converter
   - Runtime: Python 3.14
   - Upload function.zip in Code section

STEP 5: Attach the Layer to your function
   - Scroll down to "Layers" section in your Lambda function
   - Click "Add a layer"
   - Choose "Custom layers"
   - Select "unit-converter-layer" -> Version 1
   - Click Add
