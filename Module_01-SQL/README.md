# SQL Notes

The original four class files were reorganized by SQL concept instead of class number.

## Files

1. `01_DDL_DML_Constraints.sql` — databases, tables, INSERT, ALTER, keys, constraints, UPDATE/DELETE, DROP/TRUNCATE, AUTO_INCREMENT
2. `02_SELECT_FILTER_SORT.sql` — SELECT, aliases, DISTINCT, WHERE, comparison/logical operators, BETWEEN, LIMIT, ORDER BY, LIKE
3. `03_AGGREGATION_SUBQUERIES_CASE.sql` — NULL checks, conditional aggregation, GROUP BY, HAVING, ROLLUP, scalar/correlated subqueries, IN/NOT IN, CASE
4. `04_JOINS.sql` — INNER, LEFT, RIGHT, CROSS and multi-column joins
5. `05_ADVANCED_SUBQUERIES_SET_OPERATORS.sql` — SELF JOIN, EXISTS/NOT EXISTS, ANY/ALL, UNION/UNION ALL
6. `06_WINDOW_FUNCTIONS_CTE.sql` — window aggregates, ranking, LAG/LEAD, frames, RANGE/ROWS, CTEs
7. `SQL_Notes.sql` — complete master file in learning order

The examples are MySQL-oriented. Some original examples intentionally demonstrated errors; those are kept as comments so the notes remain easier to execute.
